# 📅 Word of the Day Desktop

**A clean, lightweight desktop app that shows you a new word to learn every day — and launches automatically when your PC starts.**

Build your vocabulary effortlessly with zero friction.

## ✨ Features

- **Daily New Word** — Fresh vocabulary every day
- **Auto Launch** — Starts automatically with Windows
- **Rich Word Details** — Definition, pronunciation, example sentence, part of speech
- **Minimal & Clean UI** — Designed to stay out of your way
- **History** — Browse previous words
- **Offline First** — Works without internet after initial setup
- **Customizable** — Skip words, favorite them, or adjust settings
- **Lightweight** — Runs quietly in the background

## 🚀 Quick Start

### For Users (Recommended)

1. Go to **[Releases](https://github.com/ayushshah-xo/word-of-the-day-desktop/releases)**
2. Download the latest `WordOfTheDay-Setup.exe`
3. Run the installer
4. The app will launch and add itself to startup automatically

### For Developers

```bash
git clone https://github.com/ayushshah-xo/word-of-the-day-desktop.git
cd word-of-the-day-desktop

# Install dependencies (if using Python)
pip install -r requirements.txt

# Run the app
python main.py
